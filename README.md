# TypR Website

This repository hosts the official documentation website for **TypR** — a typed programming language designed for data science and software engineering.

The site is built with [Docusaurus 3](https://docusaurus.io/) (React + TypeScript + MDX).

## Quick overview

| Branch | Purpose |
|--------|---------|
| `main` | Source code, docs, blog posts, configuration |
| `gh-pages` | Auto-generated static site deployed to GitHub Pages |

---

## 1. Getting started

### Prerequisites
- **Node.js** `>= 18.0`
- npm (or Yarn) — the project uses npm (`package-lock.json` present)

### Switch to the source branch

```bash
git checkout main
npm install
```

### Start the local dev server

```bash
npm run start
```

This opens `http://localhost:3000/typr.github.io/` in your browser. Most edits are reflected instantly thanks to hot-reloading.

## 2. Project structure

```
├── blog/                          # Blog posts (Markdown / MDX)
│   ├── authors.yml                # Blog author definitions
│   └── tags.yml                   # Blog tag definitions
├── docs/                          # Documentation pages
│   ├── intro.md
│   ├── philosophy.md
│   └── ...                        # More .md / .mdx files
├── src/
│   ├── components/
│   │   └── HomepageFeatures/      # Custom React components used on the landing page
│   ├── css/custom.css             # Global CSS overrides
│   └── pages/                     # Custom pages (independent of docs/blog)
│       ├── index.tsx              # Landing page (React)
│       ├── typr.md                # Custom /typr page
│       └── markdown-page.md       # Generic markdown page example
├── static/                        # Static assets copied as-is to the build
│   └── img/                       # Images, logos, favicons
├── docusaurus.config.ts           # Main Docusaurus configuration
├── sidebars.ts                    # Documentation sidebar configuration
├── tsconfig.json                  # TypeScript configuration
└── package.json
```

### Key files explained

| File / Folder | What it controls |
|---------------|------------------|
| `docusaurus.config.ts` | Site title, tagline, URL, navbar, footer, color mode, social links, preset options |
| `sidebars.ts` | Sidebar layout for the Documentation section (`/docs/*`) |
| `blog/authors.yml` | Author profiles shown on blog posts |
| `docs/` | All documentation content. Files here automatically get URLs like `/docs/intro` |
| `src/pages/` | Standalone pages. `index.tsx` is the homepage. Other `.md` files become routes based on filename |
| `static/img/` | Logos, favicon, and social-card image. Referenced in config as `img/...` |

## 3. How content works

### Documentation (`/docs`)
- Add a `.md` or `.mdx` file inside `docs/`.
- Its URL slug is derived from the filename (e.g. `docs/philosophy.md` → `/docs/philosophy`).
- `sidebars.ts` is set to **autogenerate** from the filesystem (`type: 'autogenerated'`), so new files appear automatically.
- You can also manually define the sidebar order if you prefer.

### Blog (`/blog`)
- Each post is a folder or a file inside `blog/`.
- The filename date prefix determines ordering (e.g. `2024-01-15-my-post.md`).
- Front-matter controls title, author, tags, etc.

### Custom pages
- `src/pages/typr.md` becomes `/typr`.
- `src/pages/index.tsx` is the fully custom React landing page.
- `src/pages/markdown-page.md` is a plain markdown page example.

### Static assets
- Anything in `static/` is served at the site root.
- The favicon (`static/img/typr.ico`) and logos are referenced in `docusaurus.config.ts` as `img/typr.ico`.

## 4. Make your first edit

1. **Start the dev server**:
   ```bash
   npm run start
   ```

2. **Edit a doc**:
   Open `docs/intro.md` and change the text.
   Save → browser updates automatically.

3. **Add a new doc**:
   Create `docs/my-new-doc.md` with some front-matter:
   ```markdown
   ---
   sidebar_position: 2
   ---

   # My New Doc

   Hello TypR!
   ```
   It will show up in the sidebar automatically.

4. **Add a blog post**:
   Create `blog/YYYY-MM-DD-post-title.md` with front-matter:
   ```markdown
   ---
   slug: post-title
   title: Post Title
   authors: [your-author-key]
   tags: [announcement]
   ---
   ```

## 5. Build and deploy

### Build locally (preview the static output)

```bash
npm run build
```

This produces a `build/` folder with the static HTML/JS/CSS. You can preview it with:

```bash
npm run serve
```

### Deploy to GitHub Pages

The project is configured for the Docusaurus `deploy` command, which builds and pushes to `gh-pages`.

**Using SSH:**
```bash
USE_SSH=true npm run deploy
```

**Using HTTPS (token):**
```bash
GIT_USER=<YourGitHubUsername> npm run deploy
```

After deploy, the live site updates at:  
`https://we-data-ch.github.io/typr.github.io/`

## 7. Tips for new contributors

- **Always work on `main`**, not `gh-pages`. The `gh-pages` branch is overwritten on every deploy.
- The site uses **dark mode by default** (`colorMode: { defaultMode: 'dark' }`). Keep that in mind when picking images or testing styling.
- If you add images, place them in `static/img/` and reference them in Markdown as `/img/filename.png`.
- The top navbar, footer links, and social-card image are all configured in `docusaurus.config.ts`.
- If you rename or delete a doc/blog file, make sure no existing link breaks — Docusaurus will error out on broken links (`onBrokenLinks: 'throw'`) during build.
