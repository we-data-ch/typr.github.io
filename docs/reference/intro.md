## Going further

This section provides a deeper overview of the Typed R language. It is intended as a practical guide to understand the core mechanisms of the type system and the main programming constructs.

Typed R is designed to scale from simple scripts to complex systems, combining the expressiveness of R with the safety and clarity of a modern typed language.
